# 🎬 CineFlix — Movie Recommender with TensorFlow.js

Personal project faithful to the **gabarito `-z`** version of the
`exemplo-01-ecommerce-recomendations` from module 01 of UNIPDS:
a web app with **MVC + event bus** that trains a **TensorFlow.js neural
network** inside a **Web Worker**, recommends movies, and **explains why
each movie was recommended**, comparing against the dataset.

100% frontend, no backend and no database. Fictional local data.

> **🌐 Languages:** [Português](README.md) · [English](README.en.md)
>
> **🔗 Links**
> - **Live (Vercel):** https://recomendador-de-filmes-rho.vercel.app
> - **Source (GitHub):** https://github.com/Hugueninfer/cineflix-recomendador

## 🚀 How to run

```bash
npm install
npm start
```

Open `http://localhost:3000`. The model **trains automatically** on load
(see the progress bar and logs). Then:

1. Select a **profile** in the top bar.
2. Click **Watch** on catalog posters (or remove from history).
3. Once the model is trained, click **Recommend**.
4. Hover any recommended card and click the **ℹ** button to see
   **why that movie was recommended** (compared to your history).
5. Use the **EN 🇺🇸 / PT 🇧🇷** button to switch the language.

> The UI never freezes during training: TensorFlow.js runs in a **Web Worker**.

## 🧠 How the recommendation works

1. **Movie vector** — each movie becomes a weighted numeric vector:
   - `genre` one-hot (weight **0.4** — the strongest signal)
   - `rating` normalized (weight **0.3**)
   - `year` normalized (weight **0.2**)
   - `average age of the movie's audience` (weight **0.1**) ← crowd signal
2. **User vector** —
   - with history: **mean** of the vectors of watched movies;
   - without history: only the user's age (genre/rating/year zeroed).
3. **Training** — builds `(user, movie)` pairs for **all** users, labeled
   `1 = watched / 0 = not watched`, and trains:
   - architecture **128 → 64 → 32 → 1 (sigmoid)**
   - optimizer **Adam (lr 0.01)**, loss **binaryCrossentropy**, metric **accuracy**
   - **100 epochs**, batch size 32
4. **Recommendation** — for every movie in the catalog, the model predicts a
   **0–1 compatibility score** and sorts from highest to lowest. The hero
   shows the **#1** in a banner.

---

## 👥 Does the model use other users?

**Yes.** It is a **hybrid** model (content + signals from other users):

- **Global training:** the `(user, movie)` pairs of **all** users feed the same
  network — the weights learn "similar profiles → similar movies".
- **Crowd feature:** every movie carries the *average age of who likes it*
  (computed on the whole dataset) — real collaborative signal inside the vector.

**Honest limit:** it is not a **pure collaborative filter** (Netflix-Prize style),
because the model does **not** learn user/item ID embeddings. The user is the
mean of their watched movies + age; the movie is features + crowd signal.

## 🔍 The "ℹ" button — explainable recommendations

Each recommended card has an **ℹ** button with a modal explaining the reason,
generated by `ExplainService` **comparing against the dataset**:

- **Item-item (collaborative):** "2 of 2 users who watched 'Matrix' also
  watched 'Back to the Future' — influence of the other profiles"
  (computed on the whole dataset, excluding yourself)
- **Genre:** "Shares the genre with 'Matrix' and 'Back to the Future' (weight 0.4)"
- **Rating:** "Similar rating to 'Toy Story' (8.8 vs 8.3) — weight 0.3"
- **Era:** "Similar era to 'Matrix' (2010 vs 1999) — weight 0.2"
- **No history:** explains that the model only used the age
- Shows the **neural network score**, **chips with your history** (the compared
  dataset) and a footer with the model weights.

This is a first step of **explainable AI (XAI)**: instead of only showing the
result, the app shows the evidence in the dataset.

## 🌐 i18n (PT/EN)

- `src/i18n/i18n.js` keeps dictionaries in Portuguese and English.
- Static texts use `data-i18n`; dynamic text uses `t('key', {params})`.
- The **EN 🇺🇸 / PT 🇧🇷** button switches language without reloading — the
  interface, catalog, recommendations and explanations are re-rendered.
- The chosen language is persisted in `localStorage` (default follows the
  browser language).
